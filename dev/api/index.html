Adaptive Refinement

Core algorithm for computing rigorous transition probabilities.

RigorousUlam2D.rel_size — Function
rel_size(F, Q_source::IntervalBox, Q_target::IntervalBox;
         enclosure_method=first_order_enclosure,
         ε=1e-6, max_iterations=100000)

Compute a rigorous enclosure of the relative measure of points in Q_source that map under F into Q_target.

Returns (lower_bound, upper_bound, uncertain_boxes) where:

  • lower_bound: Guaranteed lower bound on the relative measure (in [0,1])
  • upper_bound: Guaranteed upper bound on the relative measure (in [0,1])
  • uncertain_boxes: List of boxes that couldn't be decided

Algorithm

Uses an iterative greedy algorithm with a priority queue:

  1. Start with Q_source in the queue
  2. Always process the largest box first (greedy)
  3. For each box, compute F(box):
    • If F(box) ⊆ Q_target: add measure to lower bound
    • If F(box) ∩ Q_target = ∅: discard
    • If box width < ε: add to uncertain (upper bound only)
    • Otherwise: bisect and add sub-boxes to queue
  4. Stop when queue is empty or max_iterations reached

Arguments

  • F: The dynamical system (function)
  • Q_source: Source partition element to analyze
  • Q_target: Target partition element
  • enclosure_method: Function to compute image enclosures (default: first_order)
  • ε: Tolerance for box size (boxes smaller than ε are added to uncertain)
  • max_iterations: Maximum number of boxes to process

Example

F(x, y) = (2*x*(1-x), 0.5*y)  # Logistic × contraction
source = IntervalBox(interval(0.0, 0.5), interval(0.0, 1.0))
target = IntervalBox(interval(0.25, 0.75), interval(0.0, 0.5))
lower, upper, uncertain = rel_size(F, source, target)

RigorousUlam2D.build_adaptive_partition — Function
build_adaptive_partition(F, domain::IntervalBox{N},
                        noise::Union{IntervalBox{N}, Nothing}=nothing;
                        initial_depth::Int=2,
                        max_diameter::Union{Float64,Nothing}=nothing,
                        refinement_levels::Union{Int,Nothing}=nothing,
                        enclosure_method=first_order_enclosure,
                        safety_margin=1.1,
                        periodic::Bool=false,
                        verbose=false) where {N}

Build an adaptive partition using iterative forward flagging.

This function performs greedy refinement:

  1. Start with a coarse partition
  2. For each box, compute F(box) + noise + margin
  3. Flag all boxes that can be reached
  4. Refine flagged boxes and repeat

Returns both the partition and a boolean transition graph indicating which boxes can potentially send mass to which other boxes.

Arguments

  • F: The dynamical system
  • domain: The domain box
  • noise: Noise support box (optional)
  • initial_depth: Initial partition depth before refinement
  • max_diameter: Maximum partition diameter (stopping criterion)
  • refinement_levels: Fixed number of refinement iterations (alternative stopping criterion)
  • enclosure_method: Method for computing F(box)
  • safety_margin: Expansion factor for images
  • periodic: If true, apply periodic boundary conditions (wrap images to torus)
  • verbose: Print progress information

Returns

  • partition::UlamPartition: The adaptive partition
  • transition_graph::SparseMatrixCSC{Bool}: Boolean matrix where [i,j]=true means box i can send mass to box j

Example

F(x, y) = (0.5*x + 0.25, 0.5*y + 0.25)
domain = IntervalBox(interval(0.0, 1.0), interval(0.0, 1.0))
noise = uniform_noise_box(0.01, 2)

# Absorbing boundary conditions (default)
partition, graph = build_adaptive_partition(F, domain, noise,
                                            initial_depth=2,
                                            max_diameter=0.05,
                                            verbose=true)

# Periodic boundary conditions
partition, graph = build_adaptive_partition(F, domain, noise,
                                            initial_depth=2,
                                            max_diameter=0.05,
                                            periodic=true,
                                            verbose=true)

RigorousUlam2D.build_uniform_partition — Function
build_uniform_partition(domain::IntervalBox{N}, depth::Int) where {N}

Build a uniform partition by subdividing the domain to the specified depth.

For 2D domains, this creates 4^depth boxes via repeated quadrisection. For higher dimensions, this creates 2^(N*depth) boxes via repeated bisection.

Arguments

  • domain: The domain box to partition
  • depth: Number of subdivision levels (0 = no subdivision, just the domain)

Returns

  • partition::UlamPartition: The uniform partition

Example

domain = IntervalBox(interval(0.0, 1.0), interval(0.0, 1.0))
partition = build_uniform_partition(domain, 3)
# Creates 4^3 = 64 boxes

RigorousUlam2D.build_transition_matrix — Function
build_transition_matrix(F, partition::UlamPartition{N},
                       noise::Union{IntervalBox{N}, Nothing}=nothing;
                       enclosure_method=first_order_enclosure,
                       ε=1e-6, maxdepth=30,
                       use_lower_bound=true,
                       periodic::Bool=false,
                       transition_graph::Union{SparseMatrixCSC{Bool},Nothing}=nothing) where {N}

Construct a sparse transition matrix for the Ulam approximation of the map F.

This unified function handles both deterministic and noisy systems, with optional sparsity pattern optimization via a transition graph.

Returns a sparse matrix P where P[i,j] represents the (rigorous) transition probability from partition element j to partition element i.

Arguments

  • F: The dynamical system (function mapping R^N → R^N)
  • partition: The partition of the phase space
  • noise: Noise support box (optional, for stochastic systems)
  • enclosure_method: Method for computing rigorous image enclosures
  • ε: Tolerance for adaptive refinement (box diameter threshold)
  • max_iterations: Maximum iterations for adaptive refinement
  • use_lower_bound: If true, use lower bounds (verified transitions only) If false, use upper bounds (includes uncertainties)
  • periodic: If true, apply periodic boundary conditions (wrap images to torus)
  • transition_graph: Optional boolean sparsity pattern from buildadaptivepartition. If provided, only computes rel_size for potential transitions, dramatically reducing computation time.

Returns

  • P: Sparse transition matrix (nboxes × nboxes)
  • U: Uncertainty matrix (upper - lower bounds)

Examples

# Deterministic system with absorbing BC
F(x, y) = (2*x*(1-x), 0.5*y)
partition = build_uniform_partition(domain, 4)
P, U = build_transition_matrix(F, partition)

# Noisy system with periodic BC
partition, graph = build_adaptive_partition(F, domain, noise, max_diameter=0.05, periodic=true)
P, U = build_transition_matrix(F, partition, noise, periodic=true, transition_graph=graph)

Note

The matrix is constructed in column-major order (transitions FROM column index). Use normalize_columns! to convert to a column-stochastic matrix.
