Domain Restriction

Domain restriction is a major optimization for computing transfer operators of contracting or dissipative dynamical systems.

The Problem

Consider a map F: [-1,1]² → [-1,1]² where the image contracts, e.g., F([-1,1]²) ⊆ [-0.5, 0.5]².

Naive approach:

  • Partition the entire domain [-1,1]² into a uniform grid
  • For depth d, this creates 4^d boxes in 2D
  • Most boxes are never visited by the dynamics!

Consequence: Computing 4^d × 4^d matrix entries when only ~(4^d / r²) are relevant (where r is the reduction factor).

The Solution: Effective Domain

Instead of partitioning the full domain, we:

  1. Compute rigorous enclosure of F(domain)
  2. Add noise support (if present)
  3. Expand by safety margin
  4. Intersect with original domain
  5. Partition only this effective domain
# Automatic domain restriction
partition, eff_domain, info = create_restricted_partition(
    F, initial_domain, noise,
    partition_depth=5,
    subdivision_depth=2,  # Tighter image enclosure
    safety_margin=1.2     # 20% safety buffer
)

println("Reduction factor: ", info.reduction_factor, "×")

Computational Savings

For a reduction factor r:

QuantityWithout RestrictionWith RestrictionSpeedup
Domain volumeVV/rr×
Partition boxes (2D)4^d4^d / r²r²×
Matrix entries16^d16^d / r⁴r⁴×

Example: For r = 5 (typical for moderately contracting maps):

  • Domain: 5× smaller ✓
  • Partition: 25× fewer boxes ✓
  • Matrix: 625× fewer entries! ✓

Iterative Refinement (Recommended)

NEW: The iterative refinement algorithm with diameter-based stopping is the recommended approach for contracting maps and systems with attractors.

How It Works

The iterative refinement algorithm combines forward flagging with selective subdivision:

  1. Initialize: Start with a coarse partition (e.g., initial_depth=2 → 16 boxes)
  2. Forward Flagging: For each box in the current partition:
    • Compute rigorous enclosure: img = F(box) ⊕ noise ⊕ margin
    • Tag all boxes that intersect with img
  3. Selective Refinement: Subdivide only the tagged boxes (quadrisect in 2D)
  4. Check Stopping: If diameter ≤ max_diameter or max iterations → DONE
  5. Repeat: Go to step 2 with the refined partition

Key Insight: Boxes outside the attractor are never tagged, so they're never refined. This dramatically reduces computation for contracting maps.

Usage

# Iterative refinement with diameter-based stopping
partition, info = compute_effective_partition_adaptive(
    F, domain, noise,
    initial_depth=2,           # Start coarse (16 boxes)
    max_diameter=0.01,         # Stop when diameter ≤ 0.01
    enclosure_method=first_order_enclosure,
    safety_margin=1.2,
    verbose=true
)

println("Boxes: ", partition.n_boxes)
println("Diameter: ", info.partition_diameter)
println("Refinement levels: ", info.refinement_levels)
println("Domain reduction: ", info.reduction_factor, "×")

Why It's Better

Compared to naive partitioning:

  • Only partitions visited regions (10-100× fewer boxes)
  • Direct error control via diameter
  • Automatic adaptation to attractor geometry

Compared to standard domain restriction:

  • Standard: Computes effective domain once, then partitions uniformly
  • Iterative: Keeps refining only where dynamics actually lives
  • Result: Even more efficient for contracting maps

Performance Example

For a contracting Lorenz map:

# Naive: Partition full domain to diameter 0.0625
# Result: 256 boxes, 65,536 matrix entries

# Normal domain restriction: Compute effective domain, then partition
# Result: ~256 boxes (same!), 65,536 entries (domain is smaller but still uniformly partitioned)

# Iterative refinement: Forward flagging + selective subdivision
# Result: ~50-100 boxes, 2,500-10,000 entries
# Speedup: 6-26× fewer entries!

Theory: Error Bounds

The error bound from Theorem B:

‖f - π_δ f‖_{L¹} ≤ (δ/2) var(f)

By specifying max_diameter = δ, you directly control the error bound. The algorithm automatically determines how many refinement levels are needed.

Fixed Levels vs Diameter-Based

You can also use fixed refinement levels (backward compatible):

# Fixed number of refinements
partition, info = compute_effective_partition_adaptive(
    F, domain, noise,
    initial_depth=2,
    refinement_levels=3,  # Exactly 3 iterations
    verbose=true
)

But diameter-based stopping is preferred:

  • ✓ Direct error control
  • ✓ Adaptive to effective domain geometry
  • ✓ No need to guess depth
  • ✓ Theoretical justification

Diameter-Based Stopping

Instead of specifying partition depth, specify target error tolerance based on theoretical bounds.

Theory

The Ulam method approximation error is bounded by:

‖P - P_δ‖ ≤ C · δ

where:

  • P is the true transfer operator
  • P_δ is the Ulam approximation with partition diameter δ
  • C is a constant depending on the system

Implication: To achieve error ε, we need δ ≤ ε/C.

Usage

# Traditional approach: guess depth
partition1, _, _ = create_restricted_partition(
    F, domain, noise,
    partition_depth=5  # Arbitrary choice
)

# Diameter-based: specify error target
partition2, _, info = create_restricted_partition(
    F, domain, noise,
    max_diameter=0.01  # Directly control error
)

println("Achieved diameter: ", info.partition_diameter)
println("Number of boxes: ", info.n_boxes)

The algorithm automatically subdivides until all boxes have diameter ≤ target.

Comparison

Advanced: Adaptive Enclosures

For tighter effective domain bounds, use adaptive enclosures:

# Compute adaptive image enclosure
img_adaptive = adaptive_enclosure(
    F, domain,
    ErrorBased(1e-3, 8)  # Subdivide until error < 1e-3
)

# Add noise and margin manually
img_noisy = minkowski_sum(img_adaptive, noise)
eff_domain = intersect_boxes(
    expand_box(img_noisy, 1.2),
    domain
)

# Then partition effective domain
boxes = [eff_domain]
for _ in 1:partition_depth
    boxes = vcat([quadrisect(b) for b in boxes]...)
end
partition = UlamPartition(boxes, eff_domain)

This can provide 2-5× additional reduction over standard subdivision.

Complete Example

using RigorousUlam2D
using IntervalArithmetic, IntervalBoxes

# Contracting map
F(x, y) = (0.4*x + 0.3, 0.4*y + 0.3)
domain = IntervalBox(interval(0.0, 1.0), interval(0.0, 1.0))
noise = uniform_noise_box(0.01, 2)

# Compare approaches
println("=" ^ 60)
println("COMPARISON: Full vs Restricted Domain")
println("=" ^ 60)

# Full domain
boxes_full = [domain]
for _ in 1:5
    boxes_full = vcat([quadrisect(b) for b in boxes_full]...)
end
n_full = length(boxes_full)

println("\nFull domain approach:")
println("  Boxes: $n_full")
println("  Matrix entries: $(n_full^2)")

# Restricted domain (depth-based)
partition_depth, eff_dom, info_depth = create_restricted_partition(
    F, domain, noise,
    partition_depth=5,
    verbose=false
)

println("\nRestricted domain (depth-based):")
println("  Boxes: $(info_depth.n_boxes)")
println("  Matrix entries: $(info_depth.n_boxes^2)")
println("  Reduction: $(round(n_full/info_depth.n_boxes, digits=2))×")
println("  Matrix speedup: $(round(n_full^2/info_depth.n_boxes^2, digits=2))×")

# Restricted domain (diameter-based)
partition_diam, eff_dom, info_diam = create_restricted_partition(
    F, domain, noise,
    max_diameter=info_depth.partition_diameter,  # Match diameter
    verbose=false
)

println("\nRestricted domain (diameter-based):")
println("  Target diameter: $(round(info_depth.partition_diameter, digits=6))")
println("  Achieved diameter: $(round(info_diam.partition_diameter, digits=6))")
println("  Boxes: $(info_diam.n_boxes)")
println("  Automatic depth: ~$(log(4, info_diam.n_boxes))")

println("\n" * "=" ^ 60)
println("RESULT: $(round(n_full^2/info_depth.n_boxes^2, digits=0))× speedup!")
println("=" ^ 60)

RigorousUlam2D.compute_effective_partition_adaptive — Function
compute_effective_partition_adaptive(F, initial_domain::IntervalBox{N},
                                     noise::Union{IntervalBox{N}, Nothing}=nothing;
                                     initial_depth::Int=3,
                                     refinement_levels::Union{Int,Nothing}=nothing,
                                     max_diameter::Union{Float64,Nothing}=nothing,
                                     enclosure_method=first_order_enclosure,
                                     safety_margin=1.1,
                                     verbose=false) where {N}

Compute effective partition using iterative refinement of the forward flagging algorithm.

Algorithm:

  1. Start with coarse partition (depth = initial_depth)
  2. Run forward flagging → get effective boxes
  3. Subdivide effective boxes
  4. Repeat flagging on refined partition
  5. Continue until stopping criterion is met

Stopping criteria (use one):

  • refinement_levels: Fixed number of refinement iterations (original behavior)
  • max_diameter: Subdivide until partition diameter ≤ max_diameter (error-based, recommended)

This gives better resolution in the effective domain while keeping full domain coarse.

Arguments

  • F: The dynamical system
  • initial_domain: The full domain box
  • noise: Noise support box (optional)
  • initial_depth: Initial partition depth
  • refinement_levels: Number of refinement iterations (ignored if max_diameter is set)
  • max_diameter: Maximum allowed partition diameter (from PDF error bounds)
  • enclosure_method: Method for computing F(box)
  • safety_margin: Expansion factor
  • verbose: Print progress

Returns

(partition::UlamPartition, info::NamedTuple)

Example

F(x, y) = (0.5*x + 0.25, 0.5*y + 0.25)
domain = IntervalBox(interval(0.0, 1.0), interval(0.0, 1.0))
noise = uniform_noise_box(0.01, 2)

# Fixed refinement levels (original behavior)
partition, info = compute_effective_partition_adaptive(F, domain, noise,
                                                       initial_depth=3,
                                                       refinement_levels=2,
                                                       verbose=true)

# Diameter-based stopping (recommended - follows PDF error bounds)
partition, info = compute_effective_partition_adaptive(F, domain, noise,
                                                       initial_depth=3,
                                                       max_diameter=0.01,
                                                       verbose=true)
# Subdivides until all boxes have diameter ≤ 0.01

Compute the effective domain for Ulam discretization.

The effective domain is:

  1. Forward image: F(initial_domain)

  • subdivision_depth: Subdivision for tighter enclosure

RigorousUlam2D.compute_effective_partition — Function
compute_effective_partition(F, initial_domain::IntervalBox{N},
                            noise::Union{IntervalBox{N}, Nothing}=nothing;
                            partition_depth::Int=4,
                            enclosure_method=first_order_enclosure,
                            safety_margin=1.1,
                            verbose=false) where {N}

Compute effective domain partition using the forward flagging algorithm.

Algorithm:

  1. Create initial partition of full domain
  2. For each box B in partition:
    • Compute F(B) + noise + safety margin
    • Flag all partition boxes touched by this image
  3. Return partition of flagged boxes only

This is more efficient than computing image → partitioning because:

  • Works directly with target partition resolution
  • No hull computation needed
  • Exact boxes for Ulam discretization

Arguments

  • F: The dynamical system
  • initial_domain: The full domain box
  • noise: Noise support box (optional)
  • partition_depth: Depth of initial partition (2D: gives 4^depth boxes)
  • enclosure_method: Method for computing F(box)
  • safety_margin: Expansion factor for images
  • verbose: Print progress

Returns

(partition::UlamPartition, info::NamedTuple)

Example

F(x, y) = (0.5*x + 0.25, 0.5*y + 0.25)
domain = IntervalBox(interval(0.0, 1.0), interval(0.0, 1.0))
noise = uniform_noise_box(0.01, 2)

partition, info = compute_effective_partition(F, domain, noise,
                                              partition_depth=5,
                                              verbose=true)
# partition contains only boxes touched by forward images
# Dramatic reduction for contracting maps!
