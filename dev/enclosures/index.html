Enclosure Methods

Rigorous enclosures are the foundation of the interval-based Ulam method. An enclosure of F(box) is an interval box guaranteed to contain all images of points in the input box.

Basic Enclosure Methods

Zeroth-Order Enclosure

The simplest method: evaluate F directly on interval arguments.

F(x, y) = (x^2, y + x)
box = IntervalBox(interval(0.0, 1.0), interval(0.0, 1.0))

image = zeroth_order_enclosure(F, box)
# Returns: ([0, 1], [0, 2])

Pros:

  • Simple, always works
  • No derivatives needed

Cons:

  • Can be very loose for nonlinear functions
  • Wrapping effect compounds with iteration

First-Order Enclosure (Mean Value Form)

Uses automatic differentiation to compute tighter bounds:

image = first_order_enclosure(F, box)

The mean value theorem gives:

F(x) ∈ F(mid(x)) + DF(x) · (x - mid(x))

where DF(x) is the Jacobian matrix computed over the interval x.

Pros:

  • Significantly tighter than zeroth-order for nonlinear maps
  • Automatic via ForwardDiff.jl
  • Good accuracy/cost tradeoff

Cons:

  • Still conservative for highly nonlinear/chaotic maps

Adaptive Enclosure Methods

For highly nonlinear or expanding maps, adaptive subdivision provides much tighter bounds.

Strategy Types

RigorousUlam2D.AdaptiveEnclosureMethod — Type
AdaptiveEnclosureMethod

Abstract type for adaptive enclosure strategies.

source
RigorousUlam2D.FixedDepth — Type
FixedDepth(depth::Int)

Subdivide to a fixed depth regardless of enclosure quality.

Simple and predictable, good for benchmarking.

source
RigorousUlam2D.ErrorBased — Type
ErrorBased(tol::Real, maxdepth::Int)

Subdivide until enclosure diameter is below tolerance or max depth reached.

Adapts to local nonlinearity: refines more where needed.

source
RigorousUlam2D.ExpansionBased — Type
ExpansionBased(max_expansion::Real, maxdepth::Int)

Subdivide when image expansion is too large.

Measures ratio: diam(F(box)) / diam(box), refines when > max_expansion. Good for detecting and handling expanding/chaotic regions.

source

Fixed Depth

Subdivide to a fixed depth regardless of quality:

enc = adaptive_enclosure(F, box, FixedDepth(3))
# Subdivides 3 times: 4^3 = 64 sub-boxes in 2D

Use case: Benchmarking, known subdivision requirements

Error-Based

Subdivide until enclosure diameter is below tolerance:

enc = adaptive_enclosure(F, box, ErrorBased(1e-3, 10))
# Subdivides until diam(enc) ≤ 1e-3 or depth ≥ 10

Use case: Achieving specific accuracy targets

Expansion-Based

Subdivide when expansion ratio is too large:

enc = adaptive_enclosure(F, box, ExpansionBased(2.0, 10))
# Subdivides when diam(F(box))/diam(box) > 2.0

Use case: Detecting and handling expanding/chaotic regions

Automatic Method Selection

Let the package choose based on map characteristics:

enc = adaptive_enclosure_auto(F, box,
                               target_improvement=3.0,
                               maxdepth=10)

Decision logic:

  1. Compute both zeroth and first-order enclosures
  2. If first-order doesn't help much → use expansion-based
  3. If strong expansion detected → use expansion-based
  4. Otherwise → use error-based with adaptive tolerance

Comparison Example

using RigorousUlam2D
using IntervalArithmetic, IntervalBoxes
using Printf

# Highly nonlinear map
F(x, y) = (4*x*(1-x), 2*y*(1-y))
box = IntervalBox(interval(0.2, 0.4), interval(0.3, 0.5))

# Compare methods
methods = [
    FixedDepth(0),           # No subdivision
    FixedDepth(2),           # Fixed: 16 boxes
    ErrorBased(0.01, 8),     # Adaptive to error
    ExpansionBased(2.0, 8)   # Adaptive to expansion
]

println("Enclosure Method Comparison")
println("─" ^ 70)
@printf("%-30s | %-12s | %-8s | %-10s\n",
        "Method", "Volume", "Boxes", "Time (ms)")
println("─" ^ 70)

for method in methods
    t_start = time()
    enc, boxes, images = adaptive_enclosure(F, box, method,
                                             return_boxes=true)
    t_elapsed = 1000 * (time() - t_start)

    @printf("%-30s | %-12.6f | %-8d | %-10.3f\n",
            string(method), box_measure(enc), length(boxes), t_elapsed)
end
println("─" ^ 70)

Integration with Domain Restriction

Adaptive enclosures are especially useful for computing tight effective domains:

# Standard subdivision
eff_domain1, _, _ = compute_effective_domain(
    F, domain, noise,
    subdivision_depth=2  # Fixed subdivision
)

# Adaptive enclosure for tighter bounds
img_adaptive = adaptive_enclosure(
    F, domain,
    ErrorBased(1e-3, 8)
)
img_noisy = minkowski_sum(img_adaptive, noise)
eff_domain2 = intersect_boxes(
    expand_box(img_noisy, 1.2),
    domain
)

reduction_improvement = box_measure(eff_domain1) / box_measure(eff_domain2)
println("Additional reduction: $(round(reduction_improvement, digits=2))×")

Result: Often 2-5× tighter effective domain → further computational savings!

Performance Considerations

MethodComputation CostEnclosure TightnessBest Use Case
Zeroth-orderVery lowLooseLinear/simple maps
First-orderLowGoodGeneral purpose
Fixed depth 1-2ModerateBetterKnown subdivision needs
Error-basedAdaptiveTightAccuracy-critical
Expansion-basedAdaptiveTightChaotic systems

Rule of thumb:

  • Image computation: 1-10 ms
  • Domain restriction saves: minutes to hours
  • ROI: 100-1000× return on adaptive enclosure investment

Advanced: Custom Enclosure Functions

You can provide custom enclosure methods:

# Higher-order Taylor model (hypothetical)
function taylor_enclosure(F, box)
    # Your implementation
    return image_box
end

# Use in partition creation
partition, _, _ = create_restricted_partition(
    F, domain, noise,
    enclosure_method=taylor_enclosure,
    partition_depth=4
)

API Reference

RigorousUlam2D.zeroth_order_enclosure — Function
zeroth_order_enclosure(F, box::IntervalBox)

Compute a rigorous enclosure of the image of the rectangle box under the function F by evaluating F directly on the intervals defining the box. This corresponds to the 0-th order (pure interval) method.

source
RigorousUlam2D.first_order_enclosure — Function
first_order_enclosure(F, box::IntervalBox{2})

Compute a rigorous first-order (mean value) enclosure of the image of the rectangle box under the function F. The Jacobian matrix is obtained via automatic differentiation using ForwardDiff and evaluated over the interval box, providing a tighter enclosure than the 0-th order method in many cases.

source
RigorousUlam2D.adaptive_enclosure — Function
adaptive_enclosure(F, box::IntervalBox{N}, method::AdaptiveEnclosureMethod;
                  base_enclosure=first_order_enclosure,
                  return_boxes=false) where {N}

Compute an adaptive rigorous enclosure of F(box).

Arguments

  • F: The function to enclose
  • box: Input box
  • method: Adaptive strategy (FixedDepth, ErrorBased, or ExpansionBased)
  • base_enclosure: Base enclosure method (default: firstorderenclosure)
  • return_boxes: If true, return (enclosure, subboxes, subimages)

Returns

  • If return_boxes=false: IntervalBox enclosing F(box)
  • If return_boxes=true: (enclosure, subboxes, subimages)

Example

F(x, y) = (4*x*(1-x), 2*y*(1-y))  # Expanding map

# Fixed depth subdivision
enc1 = adaptive_enclosure(F, box, FixedDepth(3))

# Error-based adaptive
enc2 = adaptive_enclosure(F, box, ErrorBased(1e-3, 10))

# Expansion-based (good for chaotic maps)
enc3 = adaptive_enclosure(F, box, ExpansionBased(2.0, 10))

RigorousUlam2D.adaptive_enclosure_auto — Function
adaptive_enclosure_auto(F, box::IntervalBox{N};
                       base_enclosure=first_order_enclosure,
                       target_improvement=2.0,
                       maxdepth=10) where {N}

Automatically choose subdivision strategy based on map properties.

Compares zeroth-order vs first-order enclosures to detect nonlinearity, then applies appropriate adaptive method.

Arguments

  • F: Function to enclose
  • box: Input box
  • base_enclosure: Base method (default: first_order)
  • target_improvement: Desired tightness ratio (default: 2.0)
  • maxdepth: Maximum subdivision depth

Returns

Adaptive enclosure of F(box)

Example

# Automatically adapts to map characteristics
enc = adaptive_enclosure_auto(F, box, target_improvement=3.0)

RigorousUlam2D.compare_enclosure_methods — Function
compare_enclosure_methods(F, box::IntervalBox{N};
                          methods=[FixedDepth(0), FixedDepth(1), FixedDepth(2),
                                  ErrorBased(1e-2, 5), ExpansionBased(2.0, 5)],
                          base_enclosure=first_order_enclosure) where {N}

Compare multiple enclosure methods on the same input.

Returns a NamedTuple with statistics for each method.

Example

results = compare_enclosure_methods(F, box)
for (method, stats) in zip(methods, results)
    println("$method: volume = $(stats.volume), time = $(stats.time)")
end
