Enclosure Methods

Rigorous enclosures compute interval boxes guaranteed to contain all images of points in an input box.

Zeroth-Order Enclosure

Evaluate F directly on interval arguments:

image = zeroth_order_enclosure(F, box)

Simple but can be loose for nonlinear functions.

First-Order Enclosure

Uses automatic differentiation via the mean value theorem:

image = first_order_enclosure(F, box)

Computes F(mid(x)) + DF(x) · (x - mid(x)) where DF(x) is the interval Jacobian. Significantly tighter for nonlinear maps.

API Reference

RigorousUlam2D.zeroth_order_enclosure — Function
zeroth_order_enclosure(F, box::IntervalBox)

Compute a rigorous enclosure of the image of the rectangle box under the function F by evaluating F directly on the intervals defining the box. This corresponds to the 0-th order (pure interval) method.

source
RigorousUlam2D.first_order_enclosure — Function
first_order_enclosure(F, box::IntervalBox{2})

Compute a rigorous first-order (mean value) enclosure of the image of the rectangle box under the function F. The Jacobian matrix is obtained via automatic differentiation using ForwardDiff and evaluated over the interval box, providing a tighter enclosure than the 0-th order method in many cases.
