Noise and Boundary Conditions

Additive Noise

RigorousUlam2D supports rigorous treatment of additive noise through operator composition.

Noise Model

For a noisy system x_{n+1} = F(x_n) + ξ_n where ξ_n has support in box W, the noisy transfer operator is:

P_noisy = N * P_det

where N is the noise convolution operator and P_det is the deterministic transition operator.

Creating Noise Boxes

# Uniform noise
noise = uniform_noise_box(0.01, 2)  # ±0.01 in both dimensions

# Anisotropic noise
noise = anisotropic_noise_box([0.01, 0.005])  # Different per dimension

Building Noisy Transition Matrices

Use operator composition:

# Build deterministic operator
P_det, U = build_transition_matrix(F, partition,
    transition_graph=graph,
    enclosure_method=first_order_enclosure,
    max_iterations=8, ε=1e-4
)

# Build noise convolution operator
N = build_noise_convolution_operator(noise, partition,
    transition_graph=graph,
    ε=1e-4
)

# Compose operators
P_noisy = N * P_det

Periodic Boundary Conditions

For systems on the torus, use periodic=true:

# Build transition matrix with periodic BC
P, U = build_transition_matrix(F, partition,
    transition_graph=graph,
    periodic=true,
    enclosure_method=first_order_enclosure,
    max_iterations=8, ε=1e-4
)

# Build noise operator with periodic BC
N = build_noise_convolution_operator(noise, partition,
    transition_graph=graph,
    periodic=true,
    ε=1e-4
)

Periodic boundary conditions wrap coordinates to the domain, treating opposite edges as identified.

RigorousUlam2D.minkowski_sum — Function
minkowski_sum(A::IntervalBox{N}, B::IntervalBox{N}) where {N}

Compute the Minkowski sum A ⊕ B = {a + b : a ∈ A, b ∈ B}.

For interval boxes, this is simply the sum of corresponding intervals: (A ⊕ B)[i] = A[i] + B[i]

This operation is used to add rectangular/uniform noise to image enclosures.

Example

box = IntervalBox(interval(0.0, 1.0), interval(0.0, 1.0))
noise = IntervalBox(interval(-0.1, 0.1), interval(-0.1, 0.1))
noisy_box = minkowski_sum(box, noise)
source

RigorousUlam2D.noisy_image — Function
noisy_image(F, box::IntervalBox{N}, noise::IntervalBox{N};
            enclosure_method=first_order_enclosure) where {N}

Compute a rigorous enclosure of the image of box under the noisy map F̃(x) = F(x) + ξ where ξ ∈ noise.

This is equivalent to computing F(box) ⊕ noise (Minkowski sum).

Arguments

  • F: The deterministic part of the map
  • box: The source box
  • noise: The noise box (support of the noise distribution)
  • enclosure_method: Method for computing F(box)

Returns

An IntervalBox enclosing all possible images under the noisy dynamics.

Example

F(x, y) = (2*x*(1-x), 0.5*y)
box = IntervalBox(interval(0.0, 0.5), interval(0.0, 1.0))
noise = IntervalBox(interval(-0.01, 0.01), interval(-0.01, 0.01))
image = noisy_image(F, box, noise)

RigorousUlam2D.build_noise_convolution_operator — Function
build_noise_convolution_operator(noise::IntervalBox{N}, partition::UlamPartition{N};
                                 periodic::Bool=false,
                                 transition_graph::Union{SparseMatrixCSC{Bool},Nothing}=nothing,
                                 ε::Float64=1e-6, max_iterations::Int=20) where {N}

Build the noise convolution operator N on a partition using rigorous adaptive refinement.

This operator represents the spreading of mass due to additive noise. Given a probability distribution μ on the partition, N*μ gives the distribution after convolving with noise.

For uniform noise ξ ∼ Uniform(noise), the operator N[i,j] represents the rigorously verified fraction of box j that, after adding noise ξ, lands in box i. The computation uses adaptive subdivision to distinguish between verified transitions and uncertain ones.

Arguments

  • noise: Noise support box (e.g., from uniformnoisebox)
  • partition: The partition of phase space
  • periodic: If true, apply periodic boundary conditions (wrap to torus)
  • transition_graph: Optional sparsity pattern. If provided, only computes entries where boxes can overlap after noise addition.
  • ε: Tolerance for adaptive refinement (stop when box width < ε)
  • max_iterations: Maximum number of subdivision iterations per entry

Returns

  • N: Sparse noise convolution operator (n × n) with rigorously verified lower bounds

Example

noise = uniform_noise_box(0.01, 2)
partition, graph = build_adaptive_partition(F, domain, noise, max_diameter=0.05, periodic=true)
N = build_noise_convolution_operator(noise, partition, periodic=true, transition_graph=graph,
                                     ε=1e-6, max_iterations=20)

Note

  • The noise operator is independent of the dynamics F. It only depends on the noise distribution and the partition geometry.
  • Matrix entries are lower bounds (verified transitions only). This ensures rigorous approximations but may be conservative.
  • Increase max_iterations or decrease ε for tighter bounds (more computation).

source
wrap_to_torus(I::Interval, domain_min::Real, domain_max::Real)

Wrap an interval to the periodic domain.

If the interval is wider than the period, returns the full domain. If the interval wraps around, returns the full domain (conservative). Otherwise returns the wrapped interval.

Note

This is conservative: if wrapping would create a disconnected set, we return the full domain to maintain interval enclosure.

RigorousUlam2D.apply_periodic_bc — Function
apply_periodic_bc(box::IntervalBox{N}, domain::IntervalBox{N}) where {N}

Apply periodic boundary conditions to a box.

Each dimension is wrapped independently to stay within the domain.

Arguments

  • box: The box to wrap
  • domain: The periodic domain (typically [-1,1]^N or [0,1]^N)

Returns

A wrapped IntervalBox, or the full domain if wrapping creates ambiguity

Example

domain = IntervalBox(interval(0.0, 1.0), interval(0.0, 1.0))
box = IntervalBox(interval(0.8, 1.2), interval(-0.1, 0.3))
wrapped = apply_periodic_bc(box, domain)
# x wraps around: returns full domain conservatively

RigorousUlam2D.noisy_image_periodic — Function
noisy_image_periodic(F, box::IntervalBox{N}, noise::IntervalBox{N},
                    domain::IntervalBox{N};
                    enclosure_method=first_order_enclosure) where {N}

Compute the noisy image with periodic boundary conditions.

Workflow:

  1. Compute F(box)
  2. Add noise (Minkowski sum)
  3. Apply periodic boundary conditions (wrap to domain)

Arguments

  • F: The map (should map domain to itself mod periodicity)
  • box: Source box
  • noise: Noise support
  • domain: The periodic domain
  • enclosure_method: Enclosure computation method

Returns

IntervalBox enclosing the wrapped noisy image

Example

# Standard map on torus
F(x, y) = (mod(x + y, 1.0), mod(y + K*sin(2π*x), 1.0))
domain = IntervalBox(interval(0.0, 1.0), interval(0.0, 1.0))
noise = uniform_noise_box(0.01, 2)
box = IntervalBox(interval(0.9, 0.95), interval(0.4, 0.5))

img = noisy_image_periodic(F, box, noise, domain)
# Image wraps around the boundary
